# گالری نقاشی‌ها 🎨

یک سایت ساده و استاتیک (فقط HTML و CSS و JavaScript) برای نمایش نقاشی‌های دوستت.
نیازی به نصب برنامه یا دانش برنامه‌نویسی نیست.

---

## ۱. هر پوشه چه کاری می‌کند؟

| مسیر | توضیح |
|---|---|
| `index.html` | صفحه اصلی و متن‌های سایت |
| `css/style.css` | ظاهر سایت (رنگ‌ها، فونت‌ها، انیمیشن‌ها) |
| `js/data.js` | **مهم‌ترین فایل برای تو:** لیست نقاشی‌ها و تنظیمات موسیقی |
| `js/script.js` | عملکرد سایت (گالری، نمایش بزرگ، پخش‌کننده). نیازی به ویرایش نیست |
| `assets/images/` | عکس نقاشی‌ها |
| `assets/music/` | فایل موسیقی |
| `assets/fonts/` | فونت‌های فارسی (Estedad، Vazirmatn، Aref Ruqaa). داخل پروژه هستند و به اینترنت نیاز ندارند؛ دست نزن |
| `favicon/` | آیکون کوچک تب مرورگر |

---

## ۲. عوض کردن نقاشی‌ها

الان شش عکس نمونه (تصویرهای ساختگی) داخل `assets/images/` هست.

**ساده‌ترین راه:**
1. عکس‌های واقعی را روی کامپیوتر آماده کن.
2. اسمشان را دقیقاً مثل اسم‌های نمونه بگذار: `painting-01.jpg` ، `painting-02.jpg` ، ...
3. داخل پوشه `assets/images/` جایگزین فایل‌های قبلی کن (Replace).

تمام. نیازی به تغییر هیچ کد دیگری نیست.

**نکته‌ها:**
- پسوند باید همان `.jpg` باشد. اگر عکس‌هایت `.png` یا `.webp` هستند، اسم فایل را در `js/data.js` هم عوض کن (بخش ۴).
- برای سرعت بهتر، عرض عکس‌ها را حدود **۱۴۰۰ تا ۱۸۰۰ پیکسل** و حجم هرکدام را زیر **۵۰۰ کیلوبایت تا ۱ مگابایت** نگه دار. (سایت‌هایی مثل squoosh.app رایگان این کار را انجام می‌دهند.)
- در GitHub حروف بزرگ و کوچک فرق دارند: `Painting-01.JPG` با `painting-01.jpg` یکی نیست. بهتر است همه اسم‌ها با حروف کوچک باشند.

---

**قاب شناور بخش اول:** عکسی که در بخش شروع داخل قاب کوچک نشان داده می‌شود، همیشه **اولین نقاشی** لیست در `js/data.js` است. با عوض کردن ترتیب لیست، آن هم عوض می‌شود.

---

## ۳. اضافه کردن نقاشی بیشتر

1. عکس جدید را در `assets/images/` بگذار، مثلاً `painting-07.jpg`.
2. فایل `js/data.js` را باز کن (با Notepad یا هر ویرایشگر متن).
3. یک خط به لیست اضافه کن:

```js
{ file: "painting-07.jpg", title: "Painting #07", description: "" },
```

حواست باشد آخر هر خط، به جز خط آخر، **کاما** باشد.

برای **حذف** یک نقاشی، خط مربوط به آن را از `data.js` پاک کن.
ترتیب نمایش همان ترتیب خط‌هاست.

---

## ۴. عوض کردن عنوان و توضیح هر نقاشی

در `js/data.js` هر نقاشی یک خط دارد:

```js
{ file: "painting-01.jpg", title: "Painting #01", description: "این یکی واقعاً یکی از موردعلاقه‌های منه." },
```

- `file` : اسم فایل عکس
- `title` : عنوان (فارسی یا انگلیسی)
- `description` : توضیح کوتاه زیر عکس

اگر عنوان یا توضیح نمی‌خواهی، بین دو علامت نقل‌قول را خالی بگذار: `title: ""` یا `description: ""`

---

## ۵. اضافه کردن موسیقی

1. فایل موسیقی خودت را به فرمت **MP3** آماده کن.
2. اسمش را بگذار **`background.mp3`**.
3. داخل پوشه **`assets/music/`** بگذار.

تمام. پخش‌کننده در گوشه پایین صفحه ظاهر می‌شود.

**اگر اسم فایل چیز دیگری است:** در `js/data.js` بخش `window.MUSIC` را ببین:

```js
file: "assets/music/background.mp3",   // مسیر فایل
title: "Background music",             // اسمی که در پخش‌کننده نشان داده می‌شود
autoplay: true,                        // true = تلاش برای پخش خودکار
volume: 0.6                            // صدا از 0 تا 1
```

اسم جدید را جایگزین `background.mp3` کن، مثلاً `file: "assets/music/my-song.mp3"`.

**چیزهایی که باید بدانی:**
- هیچ موسیقی‌ای داخل پروژه نیست. فقط موسیقی‌ای را بگذار که حق استفاده‌اش را داری.
- مرورگرها، به‌خصوص موبایل، اجازه پخش خودکار نمی‌دهند. در این حالت دکمه پخش چشمک می‌زند و بیننده خودش آن را می‌زند. این طبیعی است.
- اگر فایل MP3 نگذاری، پخش‌کننده خودش پنهان می‌شود و بقیه سایت سالم کار می‌کند.
- برای حجم کمتر، فایل را حدود ۱۲۸ کیلوبیت‌برثانیه و کمتر از ۵ مگابایت نگه دار.
- روی موبایل، کنترل صدا نشان داده نمی‌شود چون با دکمه‌های خود گوشی تنظیم می‌شود.

---

## ۶. عوض کردن متن‌های سایت

همه متن‌ها داخل `index.html` هستند. فایل را با Notepad باز کن و متن فارسی را پیدا کن؛ فقط **متن بین علامت‌های `<` و `>`** را عوض کن. مثلاً:

```html
<h2>آثاری که ارزش دیده شدن دارن</h2>
```

فقط جمله وسط را تغییر بده و بقیه را دست نزن. بعد از ذخیره، `index.html` را در مرورگر باز کن تا نتیجه را ببینی.

ایموجی‌ها و نمادها (✦ ✨ 🎨 ❀ ♡) هم داخل همین `index.html` هستند و می‌توانی عوضشان کنی یا پاکشان کنی. فقط آن‌هایی را که کنارشان `aria-hidden` نوشته شده، دست‌کاری کن تا چیز دیگری به هم نریزد.

متن‌های اصلی به ترتیب: بخش شروع (`hero`)، گالری (`gallery`)، پیام ویژه (`message`)، پیام پایانی (`final`).

برای عوض کردن رنگ‌ها، ابتدای فایل `css/style.css` بخش `:root` را ببین؛ رنگ‌ها آنجا با اسم مشخص شده‌اند.

---

## ۷. دیدن سایت روی کامپیوتر

فایل `index.html` را دوبار کلیک کن تا در مرورگر باز شود. (فونت‌ها داخل پروژه هستند، پس بدون اینترنت هم همه‌چیز درست نمایش داده می‌شود.)

---

## ۸. آپلود در GitHub

1. در [github.com](https://github.com) یک حساب بساز (اگر نداری) و وارد شو.
2. بالا سمت راست روی **+** و بعد **New repository** بزن.
3. یک اسم انگلیسی بده، مثلاً `my-gallery`. گزینه **Public** را انتخاب کن و **Create repository** را بزن.
4. فایل ZIP را از حالت فشرده خارج کن (Extract).
5. در صفحه مخزن روی **uploading an existing file** بزن.
6. **محتویات داخل پوشه** (نه خود پوشه) را بکش و رها کن: `index.html` ، `README.md` ، پوشه‌های `css` و `js` و `assets` و `favicon`.
   - اگر فایل `.nojekyll` دیده نمی‌شود، مشکلی نیست.
7. صبر کن آپلود تمام شود، پایین صفحه روی **Commit changes** بزن.

مهم: فایل `index.html` باید **مستقیماً** در صفحه اصلی مخزن باشد، نه داخل یک پوشه دیگر.

---

## ۹. فعال کردن GitHub Pages

1. در مخزن روی **Settings** بزن.
2. از منوی چپ **Pages** را انتخاب کن.
3. در بخش **Build and deployment**، زیر **Source** گزینه **Deploy from a branch** را بگذار.
4. در **Branch** گزینه `main` و پوشه `/ (root)` را انتخاب کن و **Save** بزن.
5. یکی دو دقیقه صبر کن و صفحه را رفرش کن. بالای صفحه آدرس سایتت نوشته می‌شود:
   `https://اسم-کاربری-تو.github.io/my-gallery/`

لینک را برای دوستت بفرست. 💌

**برای تغییر بعدی:** فایل جدید را در مخزن آپلود کن (**Add file ← Upload files**) و اگر هم‌نام فایل قبلی است، جایگزین می‌شود. بعد از یکی دو دقیقه سایت به‌روز می‌شود. اگر تغییر را ندیدی، صفحه را با Ctrl+Shift+R رفرش کن.

## ۱۰. اگر مشکلی پیش آمد

| مشکل | راه حل |
|---|---|
| عکس نمایش داده نمی‌شود و اسم فایل را می‌نویسد | اسم فایل در `data.js` با اسم واقعی فایل در `assets/images/` یکی نیست (حروف بزرگ/کوچک و پسوند را چک کن) |
| گالری خالی است | احتمالاً کاما یا گیومه‌ای در `data.js` جا افتاده؛ خط‌ها را با نمونه‌ها مقایسه کن |
| موسیقی پخش نمی‌شود | اسم فایل را چک کن؛ یا فایل MP3 سالم نیست؛ یا مرورگر پخش خودکار را بسته و باید دکمه پخش را بزنی |
| سایت در GitHub Pages باز نمی‌شود | مطمئن شو `index.html` در صفحه اصلی مخزن است و Pages روی `main` و `/ (root)` تنظیم شده |
| تغییرات دیده نمی‌شوند | چند دقیقه صبر کن و با Ctrl+Shift+R رفرش کن |
